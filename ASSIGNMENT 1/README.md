## 1. Project Overview

The **Campus Smart-Parking System** is a Java-based project designed to manage parking facilities in a college campus.

The system supports:
- Vehicle entry and exit.
- Parking slot allocation.
- Parking ticket generation.
- Parking fee calculation.
- EV charging support.
- Parking pass validation.
- Slot release and management.
- Multiple parking floors.

### Concepts Used

- Classes and Objects
- Arrays and Jagged Arrays
- Constructors
- Static Members
- Inheritance
- Method Overriding
- Polymorphism
- Abstraction
- Interfaces
- Encapsulation
- Packages
- Garbage Collection

- Java JDK 8 or higher.
- Java compiler (`javac`).
